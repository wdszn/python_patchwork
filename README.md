# Python Patchwork Generator

First-year Computer Science coursework developed using Python and the University of Portsmouth's `graphix.py` graphics library.

## Features
- Generates 5×5, 7×7 or 9×9 patchwork grids.
- Supports three user-selected colours from six available options.
- Draws line, arrow and solid-colour patches.
- Uses predefined rules to determine patch placement and colours.
- Validates user input.

## Technologies
- Python
- graphix.py (Tkinter-based graphics library)

## Running the Project
1. Install Python 3.
2. Place `graphix.py` alongside the project script.
3. Run `python 2211325.py`.
4. Select a grid size and three colours.
